  <p class="landing-eyebrow">Issue · 问题反馈</p>
  <h2 class="landing-title">一条能复现的记录，比十句描述有用。</h2>
  <p class="landing-lead">反馈走 GitHub Issues。公开、可检索、可回溯，修复与否有据可查，也不需要一个字一个字地描述界面长什么样。</p>

<ul class="landing-points">
<li><strong>一个问题一条 issue</strong>便于单独跟进与关闭，也方便后来遇到同样问题的人搜到。</li>
<li><strong>写清复现步骤</strong>从哪一步开始不对，期望看到什么，实际看到什么。三步以内最好。</li>
<li><strong>附上运行环境</strong>操作系统与版本；涉及执行失败时，带上 <code class="landing-mono">$PINABLE_HOME</code>（默认 <code class="landing-mono">~/.pinable</code>）下的运行记录。</li>
</ul>
