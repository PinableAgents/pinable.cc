# Repository guidance

For local files and generated indexes, follow the [Pinable Git ignore baseline](https://github.com/PinableLab/pinable-rules/blob/main/common/development.md#git-忽略规则). Keep `.codegraph/` and local environment overrides out of Git. Preserve tracked examples and shared configuration. Follow the existing project-specific guidance in [CLAUDE.md](CLAUDE.md).
